# 🏥 Hospital Performance Dashboard  

A comprehensive hospital analytics dashboard built using **Streamlit** and **Plotly** to visualize healthcare data and generate meaningful insights for better decision-making.

---

## 📊 Features  

- Interactive KPIs (Total Patients, Admissions, Treatment Cost, Length of Stay)  
- Department Performance Analysis  
- Admissions Trend Visualization  
- Patient Distribution by State  
- Top Diagnoses Analysis  
- Cost vs. Stay Duration Analysis  
- Admission Types (Emergency, OPD, Referral)  
- Patient Outcomes Tracking  

---

## 🛠️ Tech Stack  

- Python  
- Streamlit  
- Plotly

## ▶️ How to Run  

1. Install dependencies:  
```bash
pip install -r requirements.txt
```

2. Run the application:  
```bash
streamlit run app.py
```
