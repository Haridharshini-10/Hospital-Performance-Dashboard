# Hospital Performance Dashboard

A comprehensive hospital analytics dashboard built with Streamlit and Plotly.

## Features
- Interactive KPIs (Total Patients, Admissions, Treatment Cost, LOS)
- Department Performance Analysis
- Admissions Trend Visualization
- Patient Demographics and Outcomes
- Cost vs. Duration Analysis

## How to Run
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the dashboard:
   ```bash
   streamlit run app.py
   ```
